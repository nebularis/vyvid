# Facet register

**Unit type:** Register

The facet schemes every entry is tagged with, as SKOS concept schemes: a table of the schemes and a table per scheme, one row per value, whose columns are the SKOS properties that state their meaning. A domain may extend a scheme with values of its own, and a value may have several broader values.

The values are seeded in VYD-2, when the general scope is extracted from LATTICE's facet register, which follows SWEBOK v4, DAMA-DMBOK 2, TOGAF and ISO/IEC 25010 and 25012. Until then the schemes are declared and empty.

## Schemes

| ID | Label | Definition |
|---|---|---|
| Activity | activity | What the person or agent is doing when the entry matters. A skill loaded for a task supplies it. |
| Quality | quality | The characteristic an entry protects, or trades against another. |
| Technology | technology | The technology an entry is specific to. An entry true of any technology carries none. |
