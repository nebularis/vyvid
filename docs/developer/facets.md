# Facet register

**Unit type:** Register

The facet values this project adds, as SKOS concepts: a table per scheme, one row per value, whose columns are the SKOS properties that state their meaning. A value may have several broader values.

The schemes and their general values are Вивід's own, shipped with the package. This register adds the values only this project needs, under the general schemes, and declares no scheme of its own. It has none yet.
