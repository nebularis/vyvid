# Decisions

Each decision states its context, what was decided and its consequences, in a file named `ADR-nnn-<slug>.md`, in the scope `vyvid`, so `ADR-001` here is `vyvid:ADR-001` elsewhere, here. A decision found while building is recorded as a dated addendum rather than by rewriting accepted text, and an addendum that reverses or narrows a numbered decision opens with a bold lead naming it, **Reverses decision n.** or **Narrows decision n.**
